# 네루 캐주얼 모델 V41

[Blender 모델 ZIP 다운로드](./Neru_casual_v41.zip)

팔·다리 비율 보정과 땋은 머리 위치 조정을 반영한 Blender 편집용 모델입니다.
ZIP을 풀고 `Neru_casual_v41/Neru_casual_v41.blend`를 Blender 4.3 이상에서 열어 주세요.
텍스처는 모델 파일 안에 포함되어 있으며, ZIP에 실제 모델 미리보기 5장이 함께 들어 있습니다.

ZIP의 SHA256은 `Neru_casual_v41.zip.sha256`에서 확인할 수 있습니다.
