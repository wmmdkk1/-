## 3. 미해결 문제
1. **턱이 목보다 앞으로 튀어나옴 (사용자 표시 부분, 빨간 선)**
   - 옆모습에서 턱·볼 아래가 목보다 앞으로 나와 있고, 목은 뒤쪽에 있어 머리가 목 위에 툭 얹힌 것처럼 보임.
   - 수치: 턱~볼 높이(z 0.715~0.74)의 앞쪽 끝 x = +0.059, 목 앞쪽 끝 x ≈ +0.048, 셔츠 깃 앞쪽 끝 x = -0.011. 머리 앞쪽이 깃보다 약 0.07 앞에 있음.
   - 원인: 목은 셔츠 깃에 맞췄지만(v3 수정), 머리 파일 안에서 목의 위치가 머리 무게 중심과 맞지 않음. 머리 전체가 목에 대해 앞으로 치우친 상태.
   - 제안: 머리를 목 기준으로 뒤쪽(-X)으로 약 0.04~0.05 옮겨 턱 앞끝이 목 앞끝 근처에 오게 하기. 그 뒤 정면·옆 이미지로 다시 확인.
2. **앞머리가 눈을 가림** → 단계 D에서 처리.
3. **목 아래 연결면이 열려 있음** → 셔츠 안에 들어가 보이진 않지만, 나중에 막아야 함 (단계 5 이후).
4. **머리 파일 자체가 과도하게 큼** → 단계 5에서 줄여야 함.
5. **part5 (작은 조각) 정체 미확인** → 단계 F에서 확인.
