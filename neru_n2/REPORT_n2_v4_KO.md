## 1. 이번에 바꾼 방법
v3 는 셔츠 깃 중심에 맞췄는데 깃이 V자라 실제 목 위치가 아니었음. v4 는 원래 머리 part2 를 기준으로 맞춤.

| 요청 항목 | 한 일 | 결과 |
|---|---|---|
| 1. 목 중심선 3군데, 평행 맞춤 | 목 단면을 RANSAC 원 맞춤으로 재 봄 | **실패**. 새 머리 목 단면이 높이마다 튀어서 (중심 y 가 +0.025 ~ +0.014 로 흔들림) 믿을 수 없음. 목 중심선으로 회전 맞추는 것은 하지 못함 |
| 2. 목 이음 높이에서 중심 맞춤 | 목 단면 대신 머리 전체 표면을 ICP (회전+이동+균일 크기) 로 맞춤 | 대체 방법으로 진행 |
| 3. 크기 (턱~정수리, 귀 너비, 머리높이÷키) | ICP 가 균일 크기 0.897 로 맞춤 | 머리가 원래 가정보다 10% 작아짐. 귀 사이 너비와 비율 비교는 아직 안 함 |
| 4. 얼굴·목 최근접 ICP, 차이 표 (목표 3mm 이하) | 머리 전체 ICP, 잔차 중앙값 0.0029 | 턱 앞끝 차이는 목표 미달 (아래 표) |
| 5. 목 1~2cm 겹침, 셔츠 깃 가림 | 목을 셔츠 깃 위 1.5cm 에서 자름 (나머지 131,030 정점 제거) | 옆 확대 이미지에서 확인 필요. 아직 눈으로 확인 안 됨 |

## 2. 차이 표 (model units, 키 0.90 기준. 1 unit ≈ 키의 1/0.9)
| 위치 (x = 앞뒤, 앞쪽이 +) | 원래 머리 part2 | v3 | v4 | v4 - part2 |
|---|---|---|---|---|
| 턱·볼 앞끝 (z 0.715~0.74) | +0.0227 | +0.0592 | +0.0318 | **+0.0091** (목표 0.003 미달) |
| 목 앞끝 (z 0.72~0.74) | +0.0227 | +0.0592 | +0.0318 | **+0.0091** |
| 목 뒤끝 (z 0.72~0.74) | -0.1295 | -0.1051 | -0.1277 | +0.0018 ✓ |
| 뒤통수 끝 (z 0.80~0.86) | -0.1156 | -0.0932 | -0.1163 | -0.0007 ✓ |
| 머리 앞 (z 0.80~0.86) | +0.0341 | +0.0686 | +0.0199 | -0.0142 (차이 큼) |
| 정수리 (ahoge 제외 최고점) | 0.9038 | 0.9000 | 0.8841 | -0.0197 (차이 큼) |

요약: 턱 앞쪽이 원래보다 0.009 앞에 있음 (v3 의 0.035 에서 줄었지만 아직 남음). 뒤통수·목 뒤는 잘 맞음. 머리 앞과 정수리는 원래보다 낮고 작음.

## 3. 아직 남은 문제
1. **턱·목 앞쪽이 아직 0.009 앞으로 나옴** (빨간 선 부분). 이건 ICP 가 뒤통수와 목 뒤를 우선 맞춰서 생긴 절충.
2. **정수리가 원래보다 0.02 낮음**, 머리 앞 쪽도 작음 → 머리가 전체적으로 작아짐. 크기를 0.897 → 1.0 근처로 되돌리면 턱이 더 튀어나옴. 둘 중 무엇을 우선할지 선택 필요.
3. **목 중심선 맞춤 (요청 1번) 미완료**. 새 머리 목 단면이 불안정해서 측정 방법부터 다시 잡아야 함.
4. 셔츠 깃 가림 (요청 5번) 아직 눈으로 확인 안 함.
5. 앞머리 눈 가림 (단계 D), 머리 파일 삼각형 많음 (단계 5) 은 그대로.

## 4. 선택지 (확인 부탁드림)
- A. 현재 v4 로 진행 (턱 0.009 앞, 머리 약간 작음)
- B. 머리 크기를 원래 크기에 맞추고 턱은 손으로 뒤로 당김 (턱 주변 정점 이동) → 손작업 필요, 시간 더 듦
- C. 목 중심선 측정 방법을 다시 잡고 (목 단면 전용 측정) 그 결과로 맞춤 → 요청 1번을 제대로 완성
