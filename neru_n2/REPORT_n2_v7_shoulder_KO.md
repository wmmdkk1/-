# n2 목 v7 (어깨·셔츠 깃 기준 맞춤) - 중간 보고, 미완료

## 시도한 것
1. 새 머리 파일의 '어깨 윗면 + 셔츠 깃' 영역 선택 (목 아래 z -0.080 ~ -0.048, 머리 기준 단위, 중심에서 반경 0.20 이내)
2. 몸의 같은 부분 (셔츠 몸통 윗부분, 최종 z 0.640 ~ 0.706, 반경 0.20 이내)에 최근접점 맞춤

## 결과 (모두 실패로 판단)
| 방법 | 균일 크기 | 회전 | 평균 오차 (중앙값) |
|---|---|---|---|
| 회전 허용 ±10도, 크기 ±6% | 1.18 | 10도 (한계까지 기울어짐) | 6.8mm (8.0mm) |
| 회전 허용 ±10도, 크기 0.6~1.4배 | 0.76 | 10도 (한계) | 3.4mm (3.7mm) |
| 회전 0도 (이동+크기만) | 0.57 | 0도 | 2.8mm (3.4mm) |

## 원인
- 머리 파일의 어깨 영역은 몸의 셔츠·소매 영역과 모양이 달라서 최근접점 맞춤이 한쪽으로 끌려감.
- 크기가 1.18 ~ 0.57 로 흔들림 → 머리 크기 (약 0.9 배 근처) 와 맞지 않음. 이 값으로 머리를 옮기면 앞에서 만든 머리 크기 기준이 깨짐.
- 회전은 10도 한계에 계속 걸림 → 한쪽으로 기울어진 해가 오차를 줄이는 것처럼 보임. 실제 해부학적 답이 아님.

## 그래서 한 것 / 안 한 것
- v7 블렌드는 만들지 않음 (잘못된 크기가 들어가는 파일이 되므로).
- 3가지 머리 크기 (0.94 / 1.00 / 1.06) 도 만들지 않음 (기준 변환이 아직 정해지지 않음).
- 해부학 검사 표도 아직 못 함 (기준 변환 확정 후 측정 가능).

## 다음 방법 (제안)
- 자동 최근접 맞춤 대신 대응점 랜드마크 3~4개 (양쪽 깃 끝, 목 뒤 밑점, 어깨 윗면 끝) 를 그림에 번호를 찍어서 골라 맞춤 → 회전·크기·이동을 랜드마크로 계산. 이 방식이면 기울기와 크기가 안정적으로 나옴.
- 이 방법으로 v7 을 만들고, 크기 3종 (0.94 / 1.00 / 1.06) 과 해부학 검사 표를 보고.
